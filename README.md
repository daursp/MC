## Семантика

На страницах используются теги:

- `header` — шапка сайта с логотипом и навигацией;
- `nav` — основное меню и навигация в подвале;
- `main` — основное содержимое страницы;
- `section` — смысловые блоки страниц;
- `article` — карточки практик, принципы, преподаватели, отзывы;
- `footer` — подвал сайта;
- дополнительно: `figure`/`figcaption`, `address`, `dl`/`dt`/`dd`, `blockquote`/`cite`, `form`/`fieldset`/`legend`.

У каждой страницы один `h1`, иерархия заголовков `h1 → h2 → h3` соблюдена. Для ссылок текущей страницы используется `aria-current="page"`, для декоративных элементов — `aria-hidden="true"`.

## Запуск

```bash
npm install
npm start
```

Сайт откроется на [http://localhost:3000](http://localhost:3000).

Полезные команды:

```bash
npm run dev      # запуск с автоперезагрузкой
npm run db:init  # создать базу и заполнить её данными
```

База данных создаётся автоматически при старте сервера в файле `database.db` (SQLite, встроенный модуль `node:sqlite`, Node.js ≥ 22.5).

| --- | --- | --- |

| GET | `/api/teachers` | Преподаватели |
| GET | `/api/reviews` | Отзывы |
| GET | `/api/faq` | Частые вопросы |
| GET | `/api/plans` | Абонементы |
| POST | `/api/bookings` | Отправка заявки |
